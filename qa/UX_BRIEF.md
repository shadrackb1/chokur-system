# Chokur System — UX Brief

## Users and Their Jobs

### 1. Class Teacher (Primary User)
**Profile:** Moderately tech-confident, time-poor, often on a phone or shared laptop, sometimes offline.
**Top Jobs:**
- Enter a full class's marks from a paper mark book in one sitting with zero mistakes
- Print report cards at term end
- See who is struggling and where
- Fix a mistake safely

### 2. Head of Subject
**Profile:** Needs quick insight into class and subject performance.
**Top Jobs:**
- Know which classes and subjects are weak
- Compare trends across exams

### 3. Headteacher / Deputy
**Profile:** Needs rankings, trends and printouts for meetings.
**Top Jobs:**
- View class rankings and trends
- Print ranking sheets for meetings
- Get high-level overview

### 4. First-Time User
**Profile:** Has never seen the app, needs to get to first useful result without help.
**Top Jobs:**
- Set up class, students, subjects, exam
- Enter marks
- See rankings
- Print report cards

## Priority Jobs to Optimize

1. **Enter a class's marks accurately and fast** — highest frequency, highest impact
2. **See who is struggling and where** — daily/weekly decision making
3. **Print report cards and ranking sheets** — term-end critical deliverable
4. **Set up a class, students and exam the first time** — one-time but must be frictionless
5. **Fix a mistake safely** — confidence and trust

## Device & Environment Context

- **Primary:** Cheap Android phones (390×844), shared laptops (820×1180)
- **Secondary:** Desktop in staff room (1440×900)
- **Network:** Often poor or offline; school Wi-Fi shared
- **Time:** End of long teaching day, cognitive bandwidth low
- **Input:** Touch on phone, keyboard+mouse on laptop/desktop

## Success Metrics

| Metric | Target |
|--------|--------|
| Time to first ranking (new user) | ≤ 5 minutes |
| Marks entry: 32 students × 10 subjects | ≤ 8 minutes (desktop), ≤ 12 minutes (phone) |
| First-run completion without help | 100% |
| Marks entry error rate | < 1% |
| Offline data survival | 100% |
| WCAG 2.2 AA compliance | 0 axe violations |
