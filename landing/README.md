# Landing Page Screenshots

These files are captured by Playwright during the verification step.
Run `npm run e2e` to generate them.

Required files:
- phone.png / phone.webp (390×844)
- tablet.png / tablet.webp (820×1180) 
- laptop.png / laptop.webp (1440×900)

The e2e test captures the app with seeded demo data at each viewport.
